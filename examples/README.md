# Examples

- `opening-brief-quant-qa.md` — a detailed opening brief. Briefs should be long.
- `round1-mock-project.md` — a round-1 prompt. These should be short and open;
  see `templates/round1-prompt.md` for why.
- `round2-technical-project.md` — a round-2 build project. Scope these to
  something genuinely finishable.
- `ceo-notes-round1.json` — per-candidate notes, fed into round-2 generation.
